# 专业角色的目标与相关工作连续性

2026-10-15：将本机领域目标／相关历史接入专业角色，并提供本人飞书卡片和 PWA 的目标管理与按需选用。该切片补充实施计划步骤 5；串行执行保持不变，没有启用后台委托或自动长期记忆。

## 日常使用

飞书私聊发送 `/asis`，点击「管理领域目标」，先选择研究／申请职业／生活领域并查看当前目标，再填写完整的新目标和约束、适用来源，以及是否允许本条进入既有 MiMo。保存会替换整条目标和约束；飞书每个输入最多 512 字，较长目标使用 PWA（目标 2,000 字、约束 4,000 字）。删除按钮会清空该目标、停用关联工作上下文。卡片有效 30 分钟，过期重新发送 `/asis`。

PWA「个人助手 → 管理领域目标」提供查看、编辑、保存和删除。先查看再修改；若其他入口已经更新，旧页面的修改被拒绝，需重新查看当前内容。接口不调用模型，也不会自动创建真实个人目标。

新工作中的「领域连续性」可选：只看本轮资料、采用各角色已保存的目标、采用各角色目标和相关工作历史。默认只看本轮；简单倾听仍只使用当前消息。目标未配置、未批准模型使用、已删除、待复核或来源范围不匹配时，明确显示未采用，继续使用本轮获准证据，不猜测目标。

目标适用来源必须覆盖本次选定的全部来源；例如仅绑定 Study 的目标不自动套用于 Study + Life。角色和目标均不授予来源权限。目标复核期仍为 90 天；重新保存明确的目标会重新确认，重复旧请求不能延长复核期。

本机 CLI 同样可用：

```sh
scripts/asis-agent run --source study --mode research --use-context --role-history \
  --query '合成示例：继续核查 cache 材料的原始依据与未知项' --request-id NEW_UNIQUE_ID
```

原有 `--domain`／`--with-history` 保持兼容，不能与新的专业角色上下文选项混用。恢复使用原编号和原快照，不传新的目标或历史选项。

## 隔离与可核查范围

每个专业角色只取得自己的获准目标和相关专业判断历史，不读取其他角色的目标或旧判断。总管收到本轮专业结果后核对原始证据，不直接注入这些目标文本或历史。角色结果可能复述目标，因此这不是对模型输出的信息流形式化证明。

相关历史仅从最近 200 个有结果的已完成运行筛选同领域、相同目标修订、当前可用的专业子运行；不把总管的跨领域总结作为某个专业角色的历史。按本轮问题的词项重合取最多两条、6,000 UTF-8 字节，依赖最多三层；30 天后清理。新路径不自动导入此前仅由总管保管的旧领域历史。

模型看到有限的旧问题、专业分析／局限和时间，标为先前分析，不是用户确认事实或本轮证据；旧 E 引用移除，最终仍只引用本轮原文。上下文摘要显示采用了哪些角色目标及历史数量；飞书另显示可查询的历史工作编号。

目标修订、许可、来源身份、原文版本、渠道许可、历史依赖和到期均在付费发送、付费步骤复用与结果披露前核验。修改／删除目标清理使用该修订的父子工作结果、会话与检查点；来源删除／撤权及历史失效沿既有核验／维护路径传播。其他未采用该目标的工作保留。旧付费记录和未知调用防重标记保留，不用同一编号重算。

## 传输、验证与限制

本人认证 PWA 与已绑定飞书复用既有 RAM relay；输入在 VPS 内存短暂处理，结果由 Mac 加密返回。目标、约束、根目录和密钥不写 VPS 数据库；数据库仅新增卡片页面状态等元数据。Mac 仍是目标、来源和预算的权威。修改采用期望修订检查、持久命令身份及卡片操作代次防重，重启不会盲目重发旧修改。

实际 Pi＋模拟提供商检查角色隔离、冻结快照、付费恢复、目标／原文删除与传播；真实 MiMo 在隔离合成资料中完成两轮研究工作（四次调用），后续专业调用使用一条相关历史，重复结果新增 0 Token。所有真实调用记入既有生产共享预算；完整记录见[脱敏验收](validation/agent-continuity-20261015.json)。

前端以实际 JavaScript、WebCrypto 和合成加密响应验证查看／保存／替换／删除、修订及连续性选项，并修复普通分析表单误引用 Agent 变量的问题。此验证不代替真实浏览器／手机排版验收。SDK 使用实际 AstrBot／Lark 分发与请求类型，发送 API 为替身；生产状态读取另行验证。

角色并行、渐进成果、持续委托调度、账户来源适配、自动个人事实记忆及正式任务／日历／邮件仍待实现。固定层数与最近 200 条候选会限制历史覆盖；引用格式及合成场景通过不代表所有实际问题的语义质量通过。
