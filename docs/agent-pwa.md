## 使用

登录既有 PWA，在「按需 Agent」选择 Study 或 Life，输入问题并开始。页面自动生成工作编号；保留该编号，后续查询、暂停、恢复和取消都针对原工作，不改变原问题或来源。需要新问题时清除此页或清空工作编号，再开始新工作。

请求先显示已接收，Mac 在线后核实许可并运行；「查看状态」返回已提交步骤、实际已知用量、运行状态及未知动作数。完整答案与相关证据经加密中转，浏览器本页解密；VPS 不保存明文结果或解密私钥。来源／原文变化后不再返回失效成果；状态查询不会发起模型生成。

- **暂停这项工作**：暂停整项委托与子工作，旧执行代次不能再提交，等待明确恢复。已经发送的模型请求仍可能产生用量；在途结果可能保持未知，不能把暂停解释为撤回调用。
- **明确恢复**：沿用原问题、来源和持久步骤；已提交步骤复用，未知动作继续阻塞，需要本机核对。不会更换请求编号重做未知调用。
- **取消工作**：结束该委托，不能恢复为新运行；原文不删除，已完成成果按既有保留规则处理。
- **清除此页／关闭页面**：清除当前页面结果和临时解密密钥，不停止已经开始的工作。重新打开后可粘贴原工作编号查询状态或明确恢复。

每个中转请求最多等待 15 分钟，完成后的密文仅保留 30 秒。中转过期／服务器重启后，可用原工作编号发起新的状态查询；本机保有工作和付费防重状态。Mac 离线时显示等待，不把「指令已接收」当作已执行暂停。新的运行／恢复最多同时执行一项，控制与状态查询在独立轮询路径处理，既有 PA1 分析不阻塞本切片控制。

## 权限、持久性与维护

来源和模型权限仍在 Mac；渠道上下文把 `pwa` 绑定进会话，在新工具证据返回、模型发送、历史复用和成果展示前检查远程阅读／私密阅读许可。只有模型许可不足以向本人渠道披露证据。成果去除本机绝对 URI，VPS 只在 RAM 保存有期限的问题、指令、收件公钥和密文。

Mac `work.sqlite3` 中保存工作和步骤，并新增仅含指令 ID／指纹的 `agent_channel_commands` 防重表。同一指令跨中转重启可查看当前状态，但不能再次执行旧恢复／暂停；若进程在持久接收指令后、实际执行前退出，也不悄悄重做指令，由用户查看状态后明确恢复。正文沿用 30 天到期与撤权清理，最小防重标记保留。

不新增模型、来源、费用上限、通用工具或系统服务。既有 `local.personal-asis.pa1` 服务新增独立 Agent 轮询线程与一条前台执行线程，Python 继续持有许可、预算和凭据；Pi 子进程不接触 Keychain。原 PA1 分析与 Agent 共用账本。控制在 Mac 接收后立即使旧代次失效，网络／系统调度延迟不承诺固定秒数。

VPS 的协调服务增加 RAM relay 和 `agent.sock`，PWA 增加 `/api/agent/request|result`，沿用本人会话、CSRF、HTTPS 和 Origin 检查。Mac 使用经认证的 `/v1/agent/poll|complete`。服务日志只记录异常类型，不保存问题、证据、平台错误正文或凭据。

## 验收与当前限制

实现回归共 237 项，229 通过／8 项因现有可选依赖或平台条件跳过。新增 12 项检查使用合成资料，包括真实 Pi＋模拟提供商、运行中暂停与已知用量结算、未知动作阻塞、跨工作进程恢复、旧控制指令防重、到期不调用模型、渠道撤权、无效收件密钥，以及真实 HTTP 的本人身份／CSRF／节点认证链路。合成通过不等于生产 HTTPS 或浏览器人工验收。

完整领域上下文、多角色协作、通用脚本隔离、自动长期记忆、远程权限管理和后台委托仍未交付。新版无人值守休眠／整机重启未验收。当前工具仅 `search_notes`，不创建正式任务／日历，不读新平台账号或发送第三方消息。
