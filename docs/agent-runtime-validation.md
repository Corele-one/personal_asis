# Agent 执行框架候选验证计划

状态：架构整体共识已确认，本计划等待按 [实施顺序](implementation-plan.md)执行，未开始运行。Pi 为优先候选，具体组件和版本依据验证结果决定；不将框架会话、任务或存储自动作为本系统业务权威。

## 范围

使用合成资料与模拟领域工具，模拟一个总管向知识研究、申请与职业、生活记录与复盘角色分工。验证运行框架能通过明确接口接入本系统管理的工作记录、权限、上下文和预算；不要求框架自身内建全部领域或多 Agent 管理。

现有 [PA0 Mac](pa0-mac.md)实现保留，完整 PA0 验收门槛保持有效。验证不连接真实 WUCAI、Folo、知乎或小红书账号，不接收私人原文，不执行平台写操作或自动启用持续委托。跨节点接管不在首版范围。

## 验证项目

| 项目 | 可审查结果 |
|---|---|
| 模型／工具循环 | 使用测试提供商执行查询、读取、失败反馈与调整下一步，保留事件与明确停止状态 |
| 受控执行 | 未获准工具被实际执行路径拒绝；脚本仅在合成工作目录写产物，不能通过通用能力绕过来源权限 |
| 上下文披露 | 合成私密条目的正文、标题和路径不进入未授权模型或渠道；正常阅读内容只进入相关最小上下文 |
| 委托与角色 | 角色、委托、运行和会话可独立定位；专业请求经总管路由，领域上下文分别维护 |
| 并行与预算 | 有限并行统一计入预算，同账号模拟浏览器操作排队；主动请求优先并预留容量，后台可延后，达到预算上限不再启动新调用 |
| 生命周期与恢复 | 默认停止暂停整项委托及子工作，明确恢复后继续；只停本轮／取消分别验证，重启原节点保留进度，模拟结果未知时不盲目重复副作用 |
| 长任务交付 | 先回传理解、计划和状态入口，有证据后提供标明缺口的初步成果，最终结果明确完成或受限；用户可调整方向 |
| 来源完整性 | 模拟只有摘要、媒体链接、部分历史或不可读的返回，输出明确覆盖与证据限制 |
| 精选与能力 | 代选保留理由与规则来源，移除后允许合规规则再次选入但不回写平台；未确认能力候选不能成为正式工具，关键版本／权限变化后不能沿用旧确认 |

## 交付与限制

交付候选组件比较、适配接口、合成运行证据与通过／失败项目，说明需要本系统补充的机制和更换框架的影响。具体调度器、锁、检查点格式和插件包装属于工程选择，不用以更多访谈问题替代实现核验。

纯模拟提供商通过不能报告为 MiMo 已兼容。MiMo 的实际工具调用、费用和失败行为需在端点、模型、Keychain 凭据及费用上限配置后，单独完成有限真实调用验证；本计划当前未调用模型。

具体账号、订阅规则数值、运行容量、站点配置及备份目标在各自部署切片填写，当前保留为明确配置项，不制造可运行默认凭据。总体设计依据见 [架构讨论](agent-architecture.md)。
