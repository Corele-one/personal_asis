# 双 Agent 分工与确认后的日记投影

Accepted 2026-10-20，用户明确要求重构并调整既有服务器。

此前架构把VPS当作协调／加密中转，把所有模型和资料处理汇入Mac；随后又冻结远程开发。AstrBot本身已经拥有模型、工具和会话，再包一套远程个人助手会重复职责。当前决定让Mac Pi负责知识资料，VPS AstrBot负责本人生活记录，以增量插件补齐记录、事项和受限VPS能力。

这是实际的数据驻留取舍：本人发送给AstrBot的生活文本可在VPS持久化，从而在Mac离线时继续记录；Mac原始资料保持本地。SSH只拉取生活事件与上传明确允许的状态摘要。Obsidian是按日期组织的可读投影，通过独立 `pi_sync` 命令展示完整批次并确认，拒绝则不写入。2026-10-20 用户因启动延迟明确要求解耦：`pi` 直接启动本地 Agent，取消启动时的 SSH 拉取与确认；同步时机由用户单独控制。

旧个人助手插件、协调／Relay、频道worker、旧PWA搜索与飞书卡片退役。PWA改为私人只读Dashboard，保留HTTPS／登录基础设施。历史本地Core、检索、真实付费账本与状态保留显式兼容，不迁移会话。

这修订ADR0002／0014的中转拓扑、0022／0025的默认总管分工、0035的统一Core默认及0036的“完全无自建扩展”范围。Pi仍为原生体验，仅新增窄平台写入确认扩展，不重建旧检索／会话管线。旧决定与验收保留日期意义。

完整行为、限制与验收见[总规格](../../SPECIFICATION.md)、[同步协议](../daily-sync.md)、[平台读写](../source-writes.md)。
