# 以来源所有者划分的双SQLite共享资料库

2026-10-26本人明确选择让Mac与VPS共享Life／Study可索引文本、五彩划线批注、小红书已采集正文及出处。采用相同schema的两份私密SQLite，通过既有SSH交换带来源与单调修订号的当前记录／删除标记；不用远程挂载或覆盖活SQLite文件，也不新增常驻数据库服务，以保持两端离线可用、低维护和可恢复。

Mac负责笔记与阅读资料，VPS负责生活原始记录；两端的补充各自拥有版本，修改须匹配预期版本。该取舍避免用时钟竞争覆盖来源原文，代价是共享补充不自动改写原笔记，跨文件日记写入仍保留独立预览确认；需要跨端编辑原笔记时应另行设计具体写入流程。
