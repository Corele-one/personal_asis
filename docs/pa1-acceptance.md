## 使用入口

在现有私有 PWA 的「结合资料分析」输入问题，选择全部获准来源、Study 或 Life。「按需公开研究」另外填写**公开检索词**和最多三条公开 HTTPS 原始链接；不填公开检索词时只分析本机资料。只有公开检索词到达搜索后端，问题与笔记不会被自动改写成搜索词。

已绑定本人飞书私聊支持：

```text
/asis analyze 问题
/asis research 私人问题 | 公开检索词 | 公开HTTPS链接（可选，最多3条）
/asis status 分析编号
```

原有 `/asis search` 和搜索状态入口继续工作。分析命令独立于 AstrBot 模型流，只交给 Mac 的 PA1 执行。回复可包含获准私密分析与相关摘录，不向群聊或他人开放。

本机入口：

```sh
scripts/asis-pa1 analyze --source life --query "基于记录区分自述和证据不足，不作诊断" --request-id UNIQUE_ID
scripts/asis-pa1 research --source study --query "结合已有材料提出两个可验证方向" --public-query "AI inference accelerator memory bandwidth" --url https://cloud.google.com/tpu/docs/intro-to-tpu --request-id UNIQUE_ID
scripts/asis-pa1 budget
```

普通分析完成上限仍为 512 Token；研究报告单次完成上限为 3,072 Token、提示上限 16,384 字节，按保守预留计入原有每日 100,000／每月 1,000,000 Token 共享预算。未增预算或新增模型提供商。每次选最多三条本机摘录和三条公开摘录，每条不超过 600 字符；长问题或广泛结论可能需要更具体的材料。

## 执行与失败语义

- Mac 独立 `local.personal-asis.pa1` 进程使用已有 `pa1-env`，不替换 PA0 的 Python 或阻塞 PA0 心跳。模型凭据继续只从系统凭据库读取；模型／索引来源原文不搬到 VPS。
- PWA 的临时 RSA 公钥和请求经现有认证／CSRF 路由提交。Mac 校验收件密钥、当前来源／模型许可、元数据路径及阅读／私密阅读披露许可与正文版本后调用模型，结果经 RSA-OAEP＋AES-GCM 加密；AAD 绑定编号、随机数和渠道。
- VPS 仅在 RAM 中保持请求及密文，最多 16 个请求、每个 15 分钟；已完成密文 30 秒后清除。问题不写入协调 SQLite，回答／摘录不写服务器数据库、普通日志或 Service Worker。飞书适配器在 RAM 中解密后交给既有绑定私聊，平台仍会接触回复。
- 每 3 秒的分析轮询比较来源政策、模型政策、启用状态及文件 stat 摘要；变化使待展示密文失效。正文与证据在模型前、完成后及复用前重新校验。已发给浏览器、模型或飞书的内容不声称能够追溯撤回。
- 请求身份在 Mac 共享模型账本持久化。相同请求重连只复用当前仍获准的结果；调用未知、失败输出、到期或撤权后不会自动重复付费。首次全量分段缓存构建可能需要数分钟，期间页面显示排队／处理状态；同一分析进程串行处理。
- 渠道派生回答的来源披露沿用独立的 `remote_evidence`、`private_remote_evidence` 和元数据路径检查；只有模型许可时不得在渠道展示。页面关闭会丢弃解密密钥；清除此页不取消已开始的调用。页面同一问题重复提交沿用请求编号；若明确需要新的付费分析，清除此页后再提交。服务器／飞书适配器重启会丢弃 RAM 中转与临时密钥，不承诺聊天结果跨重启恢复；Mac 仍保留计费／防重及至多 30 天的可用回答。
- 输出格式或引用不通过时拒绝展示模型断言、结算已知用量，显示明确失败；结果未知保留预留额。此轮修正了合法「不确定性引用」被误拒的问题，仍拒绝未知编号和无引用正文；引用目录由程序从正文、报告与不确定性中的实际编号生成，模型给出的冗余目录不用于扩展证据。模型正文与原始证据不会因此被重写。

## 运行维护

新增分析服务复用仓库外的 `pa1-env`；该环境需同时安装 `semantic` 与 `reader` 可选依赖（新环境可安装 `.[semantic,reader]`）。在选定发布包 `src` 的 `PYTHONPATH` 下，用该环境运行 `python -m personal_asis --home STATE_HOME pa1 channel-install` 安装／重启独立 PA1 服务；不改变 PA0 解释器。生产环境的代码发布包与回退材料仍在仓库外，切勿把真实配置、账本、报告或模型缓存提交 Git。

```sh
launchctl print gui/$(id -u)/local.personal-asis.pa1
launchctl print gui/$(id -u)/local.personal-asis.tunnel
```

Mac 休眠会中断网络，现有 SSH 隧道恢复后继续原请求；请求仍受 15 分钟中转有效期限制。到期不换编号自动付费。此次跨夜恢复时发现隧道停在退出码 255，显式唤起既有隧道后 loopback 404 表明已连到协调服务；不把这次人工恢复报告为新服务已通过无人值守休眠／整机重启验收。PA0 的历史休眠验收仍保留原日期和范围。

## 外部研究

搜索使用已有 `mcporter` 的 Exa 读取接口，网页经 Jina 公开读取。固定只读命令、不调用 shell 拼接、不加载账号 Cookie、不创建 API Key 或开通收费。公开目标禁止带凭据、查询串、片段、IP 地址和私网目的地；本机代理的基准地址解析不用于直接连接目标，真正正文由 Jina 读取。

每次记录公开问题拆分、来源路线、引用追踪、交叉核对、降级和证据缺口。内置原始来源域名是分类提示，不是可信事实保证：厂商自述不等于独立基准；其他域名保守归为 Signal，不能单独支撑关键结论。未自动追踪整条引用链或穷尽所有研究。

每条外部证据保存原始 URL、内容哈希、获取时间、页面／读取器提供的日期及其未核实状态；日期缺失明确显示未知，不把抓取日期冒充发表日期。外部证据一小时后拒绝复用；时效结论下次重新查。搜索失败继续用户明确链接，读取失败显式列缺口。真实 Exa 免费接口本轮发生限流；**提供原始链接的研究路径可用，不宣称无链接的自动搜索持续可用**。

探索输出强制包含已有材料及局限、公开证据、知识缺口、分歧与限制，以及 2–3 个方向假设；每个方向包含材料关联、能力缺口、机会、风险和下一步验证。程序核对结构、编号、本机材料关联和原始外部证据；这些检查不等于逐句事实蕴含、医疗判断或用户知识掌握程度的人工验收。不创建任务或日历。
