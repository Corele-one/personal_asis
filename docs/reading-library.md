# 本机阅读资料库

资料库用于找回本人保存过的内容，原平台保留原始资料。它独立于旧 Core、VPS 和旧单账号阅读索引；原生 Pi 按问题调用检索和阅读命令，不在启动时加载正文。

## 数据归属

本机私密 `reading-library/library.sqlite3` 保存来源账号、条目观测、账号阅读关系、内容及采集覆盖。完全相同的内容按哈希去重；每个账号仍独立指向自己实际取得的版本，不能从其他账号借用不可见正文。作者原文、划线摘录、用户批注及页面笔记分别保存；本轮不生成模型摘要或个人画像。

账号阅读关系分为五彩保存条目、小红书收藏和临时发现。关系的首次／最近观测时间不冒充平台收藏时间；没有明确收藏时间则留空。未在后续部分页面出现，不自动删除关系或推断取消收藏。

数据库目录0700、文件0600；正文、账号标签、链接、数据库、回退与采集记录都只保存在忽略的本机目录。Cookie、服务鉴权和小红书页面访问令牌仍在Keychain，不进入数据库、参数或日志。不从数据库自动上传VPS或调用云模型。

## 初始化与覆盖

```sh
scripts/asis-library initialize
scripts/asis-library status
```

默认回溯截至北京时间当天的90个自然日。WUCAI中国区按最多14天窗口读取，每窗口每次最多10页、每页请求20条，保留分页检查点；可用 `--since YYYY-MM-DD --until YYYY-MM-DD --max-pages 10` 指定范围。没有自动网络重试，失败后保留已入库条目与最后完整页面的继续位置；再次显式运行可继续。已结束的同一日期窗口会跳过，检查时间仍是原时间，不表示实时同步。

小红书复用本人已经登录的独立MCP，只读取每个账号收藏tab当前返回的页面（最多接受100条），不滚动补抓历史、不采集推荐流或点赞，不进行平台写入。页面访问令牌按账号和条目存入Keychain，供后续按需补取正文。风险提示、失去登录或未知结构会停止该账号读取，不尝试绕过。

覆盖记录区分 `window_exhausted`（仅该日期查询结束）、`visible_page_only`（仅可见页）、`page_limit`、`pagination_unverified` 和 `failed`。所有情况都不宣称完整账号历史；WUCAI条目也不冒称剪藏全文。

首次会从启用的旧缓存迁入可验证且未到期的条目，继承原取得时间、正文归属和遗忘排除；旧文件保持原样。旧小红书缓存只归原账号，不分配给新账号。旧Markdown无法恢复的“某条批注具体对应哪段多行划线”不猜测关联，后续平台详情可提供新版本。

## 找回与按需读取

```sh
scripts/asis-library search --query 器件仿真
scripts/asis-library search --source xiaohongshu --account second --query 搜索词
scripts/asis-library read --source wucai --account cn --item-id 条目ID
scripts/asis-library fetch --source xiaohongshu --account second --item-id 条目ID
```

`second` 是示例账号标识；实际标识由本人私密配置给出，原小红书账号仍是 `default`。跨账号搜索返回账号信息，阅读与补取必须明确来源、账号和条目。三字及以上检索使用FTS5 trigram；一至二字使用字面子串查询，避免中文短词无法命中。结果先返回标题与出处，`read` 再返回完整已采集内容及归属。

`fetch` 只接受该账号已采集且仍可用的条目。小红书需要该账号有效的页面访问令牌；没有令牌或已失效则停止，不能拿另一账号的令牌替代。新鲜列表元数据不会覆盖已取得正文，也不会无故延长临时正文的留存时间。旧缓存页面令牌未批量迁移，重新读取当前可见列表后会取得对应账号的新令牌。

五彩保存条目和小红书收藏长期保留；迁入的临时发现沿用原30天有效期，到期查询立即拒读，不声称备份同时消失。当前没有新增定时采集或清理任务。关闭来源配置后查询停止使用对应账号。

```sh
scripts/asis-library forget --source xiaohongshu --account second --item-id 条目ID
```

遗忘仅作用于本资料库的该账号记录：停止检索、排除再次导入，并清除不再被其他账号引用的当前内容。原平台、旧缓存、已生成的Pi会话及回退备份各自独立，需要单独处理；不能将此命令描述为全系统删除。

## 验收边界

合成验收覆盖跨账号去重与隔离、中文检索、正文保留、过期拒读、遗忘排除、凭据内容拒收、私密权限、并发写锁、分页失败续读和可见页不推断取消收藏。真实采集条数、窗口覆盖、正文补取和标题定位另行记录；不以合成测试或标题字面命中冒称语义检索质量通过。
