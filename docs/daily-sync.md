# AstrBot 到 Obsidian 的确认同步

VPS `LifeStore` 以平台／本人／消息身份的哈希为记录 ID，记录保存原话、整理、类型、所属时刻、北京时间日期、修订号与删除状态。变化表有单调序号。SSH 固定命令 `life_export` 接受仅含整数 `after` 的 JSON，一页最多200项；Mac 每次最多拉10页，余下下一次继续。没有由模型提供的远程 shell 命令、目录或 SQL。

Mac 保存拉取游标、每个记录最新版本和已确认日记位置。拉取不代表已确认；本机收据只在写入后更新。拒绝整批后，下次继续显示。单进程同步锁避免同时确认两批。非交互终端不拉取、不提问、不写日记。

目标从既有 `sources.yaml` 的 Life 源获得，相对目录 `Calendar/Journal/Daily`，日期使用 Asia/Shanghai。每条记录用稳定的 `astrbot:ID:start/end` 注释包围；原话以引用块显示，模型摘要标为可修正。正文中的伪标记无法成为顶层同步区块。

预览包含每个目标文件的完整 diff。用户输入“确认写入”后，复核文件内容没有变化、目录未越界／成为符号链接、目标未被排除，再逐文件原子替换。修订更换对应区块，日期纠正移除旧日区块并写入新日，删除只移除该条记录。其他手记／标题保留。

多文件不提供整体原子事务；中途失败会留下已写入的部分文件，下次按稳定标记重新计算并再次确认。已写但尚未来得及存收据的记录不会再次追加。发生手动破坏的标记、文件并发更改时停止，不覆盖未知内容。

VPS 删除时清空记录及变化历史中的正文，并同步 tombstone；Mac 成功拉取后不再保留该记录待同步原话。Obsidian 已有副本的删除仍须本人确认。离线电脑、iCloud历史、AstrBot聊天历史和其他备份不属于自动撤回覆盖。

Mac 同步后通过另一个固定 SSH 接口上传计数、最近检查时间、来源是否配置。自动同步没有笔记正文／根目录／凭据，Dashboard 不从该摘要推断实时在线或账户连通。配置／运行／回退见运维（旧说明已退役，见[当前规格](../SPECIFICATION.md)）。

选定Mac摘要的发布属于独立的 `source_write` 确认动作，不随启动同步自动上传。见[平台与看板写入](source-writes.md)。
