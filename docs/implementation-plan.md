# 实施计划

本轮目标：Mac 知识 Agent 与 AstrBot 生活 Agent 协作，替代旧统一执行／远程中转架构。

1. 实现独立生活事件存储、AstrBot本人收录／整理工具、明确时间事项提醒与受限VPS草稿目录。
2. 实现Mac启动SSH增量拉取、按北京时间日期生成Obsidian日记预览、整批确认、修订／删除／幂等和离线继续Pi。
3. 加入原生Pi平台写入确认：WUCAI日记／批注／状态、小红书点赞／收藏／评论，保留既有Keychain和只读接口。
4. 以私人只读Dashboard替换旧PWA，展示生活记录和Mac状态摘要，保留原HTTPS及登录哈希。
5. 删除旧协调／Relay／飞书助手／旧PWA与部署、相应测试及重复文档；保留历史本地工作、真实状态、凭据和服务器回退材料。
6. 完成合成回归、实际SDK与MCP工具目录检查、VPS部署／下线检查、Mac启动和SSH同步验证；记录真实聊天／写入／提醒仍需各自验收。

本轮最终执行状态见[当前状态](project-status.md)与验收记录（旧说明已退役，见[当前规格](../SPECIFICATION.md)）。

后续按使用反馈推进：真实生活整理质量、到期提醒投递、睡眠配对复盘、附件／餐食识别、更多经过确认的平台写操作、Mac内容的显式选定展示。没有本轮授权的自动社交发布、整库上云、通用shell执行、自动日历或跨Agent任意委托。
