## 6. 持续运行与自动代选

为每项启用的委托配置主题、获准来源、触发／频率上下限、到期与停止条件、预算和通知规则。实现增量领取、动态频率、主动请求容量预留、后台延期、普通成果汇总和需介入／到期风险／持续失败提醒。

“停止这项工作”暂停整项委托及子工作，保存成果，等待明确恢复；原节点离线后继续等待，不自动迁移。代选仅在用户认可的条件和数量上限内运行，记录代选理由、规则与出处；移除当前精选后允许以后再次合规选入，但不能恢复已被撤销的来源权限。

用真实运行观察验证恢复、费用和噪声控制，再扩大来源或并行容量；具体数值作为可见配置，不由模型擅自扩大。
