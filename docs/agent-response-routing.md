# 回应方式、检索时间与答案分区

2026-10-15 用户反馈后修复：旧流程对每项按需工作强制先搜索笔记，语义相似的旧日记会进入本轮分析；卡片把系统回执、模型回答及证据摘录展平，无法清楚辨认谁在说话。核对实际工作确认了这两处问题，真实问题、笔记及原文不进入 Git。

## 本轮行为

- 在「总管自动分工」或「生活复盘」中，明确的简单安慰／鼓励／倾听请求，且没有要求检索、结合记录或分析，直接回应当前消息。也可显式选择「倾听与鼓励（不读笔记）」或 `conversation`。该路径不读取笔记、不加载语义模型、不执行工具或专业角色，仅一次 MiMo 调用，沿用共享预算、防重及本人渠道限制。
- 要求结合日记、笔记或历史分析时仍走原检索路径。这是有限规则路由，不是完整自然语言意图规划，也没有把所有普通问题改为无检索回答。显式研究／职业／多角色方式继续按所选流程执行。
- 可识别最近／过去 N 天、周或月，以及今天、昨天、本周、本月、上个月。时间范围在新工作开始时冻结，后续工具改写检索词不能扩大它。相对月数按每月 30 天；单说「最近」并涉及日记／记录／复盘等时，按近 30 天并在卡片明示。任意绝对日期区间及复杂时间表达尚未实现。
- 时间过滤依据文件名或 frontmatter 的明确笔记日期，排除日期不明／冲突的材料，不用文件修改时间冒充记录日期。窗口内无证据时保留缺口，不回退到几个月前的笔记。笔记日期也不等于事件发生时间；历史自述不能当成本轮现状。
- 卡片分别显示「你的问题」「系统状态」「Agent 的回答」「回答的局限」「本次检索范围」「参考资料」及「专业角色进度」。原文以 E 编号、笔记日期和摘录显示，明确标注不是 Agent 回答；专业角色进度不是专业角色原始答案。无答案时明确显示尚未生成。所有动态内容仍为 plain_text，超长显示会截断。
- PWA 同步标注 Agent 回答、原文摘录、笔记日期及本轮无检索说明。直接回应的本人消息仍按私密处理；服务器不持久保存问题或答案。

旧工作维持原已付费协议、提示与结果，查看／恢复不自动改写旧答案，也不偷偷换编号重算。刷新旧卡片可得到新的显示分区；要使用新回应路由需明确新建工作。

## 验证边界

本轮回归、真实 MiMo 合成输入及生产发布信息见[脱敏验证](validation/agent-response-20261015.json)。实际旧工作缓存复用新增模型 Token 为 0；合成鼓励请求一次调用、0 次检索、0 条证据，重复查看 0 Token。保留历史两笔未知调用预留。

新卡片的实际手机排版及真实个人新请求回答质量仍需真人复核。现有混合检索的总体相关性排序、所有中文时间表达及事实／因果语义正确性没有因本次修复而全部验收；未增加后台工作、来源、提供商或预算。
