## Learning 栏与统一追踪页

日记中的Learning同步内容应位于`--- end-multi-column`之前，不能追加到End-of-Day或页尾嵌入之后。按实际主题H4分组：

```markdown
### 📖Learning

#### 模拟电路

- **23:38 · 结束**
  学完了今天的复习内容。
  待解决：共模增益还需要核对。

--- end-multi-column
```

活动投影不再生成`asis-learning`／`asis-habits`身份注释，旧块只在完整预览确认后迁移。删除或修订跟踪本机收据；手写内容保留，已改过的受管正文停止核对。旧的Missing／C++／Research三项只有全部未勾选时才清理，不删除手写完成记录。

统一学习追踪页按实际主题自动发现，提供年份、主题和关键词筛选、日历热力图、记录天数、主题数与近期条目。点击日历查看当天，点击日期回原日记。自定主题的手写段落也可回看；旧DDCA等字段和学习任务的已勾选项标为“旧打卡”，未勾选待办不统计。空白不等于未学习；结束、旧打卡和手记分别标明，不推算实际专注时长。

视图只读取所选年份的日记，最多16篇并发；读取失败显式提示统计不完整。数据仍在原日记中，追踪页不另建学习数据库、不自动写文件或访问网络。复用现有Dataview JavaScript设置，不改全局样式或插件配置。
