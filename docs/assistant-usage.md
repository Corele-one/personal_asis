# 使用指南

## Mac Pi

直接运行 `pi`。启动前先从 VPS 拉取新记录；有待同步时显示对应日期、完整文件路径及修改。输入“确认写入”执行整批；回车／其他输入跳过。同步完成或 VPS 离线后继续原生 Pi。`pi --plain` 不加载个人配置；`pi --check` 不读取凭据或调用模型。

可让 Pi 在 Study／Life 查找和阅读相关原文、整理笔记草稿，按需读取 WUCAI 划线／批注和小红书。修改笔记前先看改动再确认。平台写入使用 `source_write`：WUCAI 追加今日日记、改页面笔记／文章状态；小红书点赞、收藏、评论。原生确认窗口显示确切操作和内容，拒绝则不执行，网络结果未知时先去平台核对，不重复执行。见[平台写入](source-writes.md)。

## VPS AstrBot

沿用已有本人私聊。普通文本自动保存为生活原话，AstrBot 可以按需分类和摘要。例如：

- “准备睡觉了。”／“我刚起床。”：作为自报作息事件，不推断实际睡眠。
- “今天跑步后有点累，先记一下。”：健康／日常自述，不作诊断。
- “明天晚上八点提醒我提交材料。”：AstrBot 根据当前时间解析明确时间，工具保存后才算设置；有歧义会询问。
- “刚才那条是补记昨天晚上十点。”：明确修正所属日期，下一次同步将显示移日改动。

`/life` 查看状态，`/life list` 查看近期原话及完整记录 ID，`/life delete 完整ID` 删除 VPS 正文。已写入 Obsidian 的相应区块需要下次启动时确认移除。平台消息历史和备份不随插件删除自动消失。

`life_recent` 读取近期生活记录；`vps_workspace` 可在独立生活工作目录保存 Markdown 草稿、读取草稿和检查时间／磁盘。它不提供任意 shell、sudo 或其他项目访问。

## Dashboard

打开已有私人 HTTPS 入口，使用原密码登录。展示 AstrBot 最近100条记录、提醒状态，以及 Mac 最近一次同步检查和来源配置。Mac 默认仅展示状态摘要，原始笔记不会自动上传。如需展示某份整理结果，明确让 Pi “把这个摘要发布到私人看板”，经 `source_write` 的 Dashboard 操作预览完整标题／正文并确认后上传，看板显示最近确认的一份。PWA 可以安装，但个人内容不提供离线缓存；“来源已配置”不等于实时账户登录有效。

## 单独同步与兼容

运行 `scripts/asis-life-sync` 可以不进入 Pi 而进行同样的预览／确认。没有 `--yes` 或自动确认模式。JSON／RPC／print 模式需要单独交互同步，不消费管道输入作为批准。

旧本机会话可使用 `pi --engine conversation`／`pi --engine legacy`；它们不使用新 AstrBot 和同步协议。旧 `/asis`、飞书卡片和远程搜索页面退役。真实聊天与记录质量的验收范围见[当前状态](project-status.md)。

## 已初始化的起始背景

Mac Pi的私密 `knowledge-context.md` 包含已读资料地图和带出处的使用背景，按问题需要读取。AstrBot的 `life_context` 按需读取本人选定30天范围的生活背景；看板单列“近期生活背景”，不混入新消息。可用 `/life forget-context` 删除当前VPS起始背景及其工作区说明。原日记、Mac初始化文件、平台历史与回退备份需分别处理。
