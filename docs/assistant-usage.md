# 使用指南

智能编排复用已获准MiMo，只发送当天Freewrite与待排原话，不改写正文。相同输入复用方案；失败时暂缓日记，资料同步继续。`pi_sync --retry-layout`主动重试，`pi_sync --layout plain`只预览原话追加。

## Mac Pi

直接运行 `pi` 打开本地原生 Pi，启动不执行同步、不等待 VPS。运行 `pi_sync` 分三步处理VPS生活记录、Mac资料刷新、共享数据库增量交换。只有 `/life` 主动记录的生活自述结合当天Freewrite文字编排：相关补充紧接对应段落，沿用已有主题，独立话题才补具体H4，均在 `---` 上方，分节符前空一行，不进入后面的分栏卡片，也不保留 `astrbot:…` 注释；定位信息只保存在私密收据，问候、命令、日期碎片、提醒与作息回执略过，习惯／学习归原栏目。日记输入“确认写入”才执行，回车暂不写入，`d`看原始diff；跳过日记仍刷新资料与同步已授权共享文本。Life／Study笔记索引文本、五彩与小红书已采集资料按[共享范围](shared-library.md)进入VPS副本，凭据、附件与原库保留Mac；背景摘要更新仍另行确认。`pi --plain`不加载个人配置；`pi --check`不读取凭据或调用模型。

可让 Pi 在 Study／Life 查找和阅读相关原文、整理笔记草稿，按需读取 WUCAI 划线／批注和小红书。修改笔记前先看改动再确认。平台写入使用 `source_write`：WUCAI 追加今日日记、改页面笔记／文章状态；小红书点赞、收藏、评论。原生确认窗口显示确切操作和内容，拒绝则不执行，网络结果未知时先去平台核对，不重复执行。见[平台写入](source-writes.md)。

小红书有多个账号时，请在请求中说明账号名，Pi 会选择对应 MCP。点赞、收藏和评论的确认框也会显示该账号；未指定账号不会自动选择。新增账号的收藏不并入旧单账号缓存，见[多账号接入](xiaohongshu-setup.md)。

初始化[本机阅读资料库](reading-library.md)后，可以让Pi“找出我收藏过的某类资料”，并说明账号或来源。Pi先搜索资料库、阅读命中原文，必要时补取详情；WUCAI与两个小红书账号的资料可统一查找，账号关系仍分别保留。无命中时可以继续通过平台查找；没有命中不表示从未收藏。

## VPS AstrBot

沿用已有本人私聊。普通文本保存为助手对话记忆，不进入Obsidian；要写随记使用 `/life` 加正文，AstrBot 可以按需分类和摘要。例如：

- “准备睡觉了。”／“我刚起床。”：作为自报作息事件，不推断实际睡眠。
- “/life 今天跑步后有点累，先记一下。”：健康／日常自述，不作诊断。
- “明天晚上八点提醒我提交材料。”：AstrBot 根据当前时间解析明确时间，工具保存后才算设置；有歧义会询问。
- “/life 刚才那条是补记昨天晚上十点。”：明确修正所属日期，下一次同步将显示移日改动。

`/life` 查看状态，`/life list` 查看近期原话及完整记录 ID，`/life delete 完整ID` 删除 VPS 正文。已写入 Obsidian 的相应区块需要下次运行 `pi_sync` 时确认移除。平台消息历史和备份不随插件删除自动消失。

普通交流与助手记忆不需要 `/life` 前缀；想把自述写进日记时用 `/life`。明确提醒请求仍可以自然提出，单独保存为事项。`/life 今天做完实验了，但有点累` 也可以：非管理命令内容会保存，简短回复“已记下”，随后由当前AstrBot会话自然回应。多行、空格后的内容完整保留；`status`、`list`、`delete`、`sleep`、`context`、`forget-context`、`goodnight` 仍是管理命令。关闭收录也能聊天，只有保存成功才有成功回执。AstrBot可能在分发插件前剥除斜杠，插件同时排除剥除前后的管理命令文本，避免误记为日常。群聊不收录。

已配置的催睡规则按北京时间每天凌晨01:00起，每5分钟提醒，一直持续到收到你的晚安，白天也不会自动截止。直接发“晚安”“睡觉了”或“我准备睡觉了。”会确定性保存为睡前自述，并停止当晚催睡，不需要等模型分类；`/life goodnight` 也可以。前一晚中午至当天中午视为同一睡前窗口，下一晚规则自动继续。长段叙述、引用、否定、问句、补记不会自动当成停止信号，可另发一句“晚安”。自述不代表实际入睡或实际睡眠时长。

| 命令／完整文本 | 用途 |
|---|---|
| `/life sleep` | 查看开关和下一次提醒时间 |
| `/life sleep off` 或“关闭睡觉提醒” | 关闭每天的催睡规则 |
| `/life sleep on` 或“开启睡觉提醒” | 开启每天规则；首次／重新开启从下一个01:00起，保留当晚已说晚安的状态 |
| `/life goodnight` 或“晚安”／“睡觉了” | 停止当晚催睡，并在收录开启时保存睡前自述；也兼容 `/life 我睡了` |

规则保存在VPS，Mac离线不影响它。VPS或飞书离线期间不能保证送达；恢复后不补发积压提醒。未知结果的那一次不自动重试，下一次五分钟催睡仍继续。

`life_recent` 读取近期生活记录；`vps_workspace` 可在独立生活工作目录保存 Markdown 草稿、读取草稿和检查时间／磁盘。它不提供任意 shell、sudo 或其他项目访问。

2026-10-21本人明确授权后，已将既有绑定的本人飞书ID加入默认配置管理员，保留 `computer_use_require_admin=true` 和原有其他管理员。本人飞书使用默认配置的 `computer_use_runtime=local`；另一份 `pig` 独立配置没有路由到这一本人飞书私聊。原生SDK具备shell／Python／文件工具，Agent上限30步、工具超时120秒；无须额外插件才能形成基本工具循环。`local` 以AstrBot服务的 `mac` 用户在VPS本机执行，生活草稿工具的目录限制不覆盖原生shell；`sandbox` 则使用另行部署的运行环境。配置生效与模型实际选择／执行工具分别验收，未发送飞书测试消息。

## Dashboard

打开已有私人 HTTPS 入口，使用原密码登录。展示 AstrBot 最近100条记录、提醒状态，以及 Mac 最近一次同步检查和来源配置。Mac 默认仅展示状态摘要，原始笔记不会自动上传。如需展示某份整理结果，明确让 Pi “把这个摘要发布到私人看板”，经 `source_write` 的 Dashboard 操作预览完整标题／正文并确认后上传，看板显示最近确认的一份。PWA 可以安装，但个人内容不提供离线缓存；“来源已配置”不等于实时账户登录有效。

## 单独同步与兼容

运行 `pi_sync` 进行 Mac/VPS 同步、预览／确认并上传允许的 Mac 状态摘要，不启动 Pi。仓库入口为 `scripts/pi_sync`，兼容 `scripts/asis-life-sync`。系统 `sync` 保持原有行为。没有 `--yes` 或自动确认模式。JSON／RPC／print 模式需要单独交互同步，不消费管道输入作为批准。

旧本机会话可使用 `pi --engine conversation`／`pi --engine legacy`；它们不使用新 AstrBot 和同步协议。旧 `/asis`、飞书卡片和远程搜索页面退役。真实聊天与记录质量的验收范围见[当前状态](project-status.md)。

## 在看板中纠正内容

点击“和 Agent 聊聊”开始对话；要改某条内容，先点生活记录、Habits或Learning旁的“纠正这条”。例如：“这是实践作业要求，不是我读过的书，请去掉这条阅读记录。”Agent会复用当前AstrBot的模型核对选中记录，修改后显示前后结果；原话保留。普通反馈对话不自动写随记，Mac原日记仍须下次`pi_sync`预览确认。

若记录已在别处更新，刷新后重新选择；“处理结果未确认”不会自动重发模型请求，先看改动回执并核对记录。该入口不修改来源授权、平台账号或Mac文件。见[反馈流程](human-feedback.md)。
