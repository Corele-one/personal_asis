## 计划与执行

`agent run --mode auto|research|career|life|team` 启用总管协作。auto 根据问题中的公开可见领域词生成可查看的确定性路由，未匹配则交给研究角色；不是模型对用户身份或心理状态的推断。显式角色覆盖自动路由，team 选择三个专业角色。原来不带 mode 的已付费和新工作均保留原协议。

程序先在明确选择的获准来源中检索一次，计入原三次检索上限。总管按计划依次给所选专业角色分工，分别创建同一委托下的子运行与独立会话身份；每个专业角色进行一次不带工具的 MiMo 判断，随后总管执行既有 Pi 检索／模型循环并汇总。专业角色不能自行调用工具、跨角色转派或扩大来源。

第一版串行上限为一个专业角色，父运行保留控制权；不是并行角色或独立持续调度。每个专业角色只接收本次最小原始证据、本次问题和与其角色匹配的显式领域目标；不接收其他角色目标、历史或分析。总管只接收通过引用／格式校验的有限分析摘录，最多每角色 1,200 字节答案与 500 字节局限，以及本次原始证据。三个角色的看法不构成三份独立证据。

研究角色核对概念、材料支持与冲突。申请职业角色区分个人目标、经历与约束，不能捏造当轮要求、日期、概率或收入保证。生活角色区分本人自述、他人描述与暂定解释，不作诊断、不将缺记录视为未发生、不把自报作息当成精确睡眠时长。这些是受控提示和输出要求，引用校验不自动证明语义正确，仍需复核。

## 本机与渠道

```sh
scripts/asis-agent run --mode auto --source study --query '比较已有材料支持的机制差异' --request-id role-work-001
scripts/asis-agent run --mode team --source study --source life --query '结合材料比较申请准备与生活约束' --request-id role-work-002
scripts/asis-agent resume --request-id role-work-002
```

已有 `--domain research --with-history` 仍为显式本机选用能力；领域目标必须已有本人确认和模型许可。仅匹配的专业角色接收该目标，历史只交给总管，不把其他领域目标注入专业角色。PWA／飞书可选择角色，但本轮仍不提供远程编辑领域目标或自动提取个人事实。

PWA 新增工作方式选择和 Study + Life 范围，显示实际计划及状态。飞书采用 `/asis agent study career | 问题` 或 `/asis agent study,life team | 问题`；省略角色保持旧流程。控制命令不允许附带新的角色、问题或来源，跨渠道恢复保留原付费输入。

## 状态、费用和撤销

全部角色共用本机预算账本、来源／模型／目的渠道政策，模型请求发送前事务预留预算。专业判断每次最多 768 个输出 Token，且不超过原配置上限；总管保持原限制。全工作最多三次专业判断、六轮总管模型、三次检索、六条证据，没有新增网络或执行工具。

专业调用的完整请求指纹、已知用量和输出保存在父运行的事务步骤里，子运行保存相应领域进度／结果。进程结束后重建原请求，已付费步骤免费复用；后续新增证据不能改变早先专业判断的输入快照。修改角色计划、来源、模型或协议不能改写旧工作；旧编号不能升级流程。每次复用、模型发送和结果发布都核验当前原文及权限。

暂停或取消同一委托会隔离父子运行；正在外部执行的调用可能仍产生已知用量，但不能继续提交旧代次。未知调用保留预留和防重标记，不能通过新租约重复执行。源码协议变化后旧协作会话拒绝复用，旧直接分析协议不变。

正文和角色结果沿用原 30 天保留；撤权、原文失效或会话清理会删除委托下相关运行的正文／结果／检查点。来源原文保持只读，必要计费和防重身份保留。VPS 仍只保存路由与允许的元数据，模型输入／结果仅加密中转。

## 验收边界

合成回归覆盖独立角色输入、父子身份、共享预算、已付费检查点恢复、额外检索后的稳定复用、暂停中的代次隔离、未知防重、删除／撤权清理、非法引用收费后拒绝、领域目标隔离、旧协议保护及渠道身份。
