# PA0 文本阅读与可选能力

PA0 已按 Mac 单节点范围验收。当前 Mac 来源只启用 Markdown；获准的非私密及私密摘录／正文可按需加密显示，私密阅读另设独立许可；模型与源级持续权限见[确认方案](private-data-authority.md)。ROG 格式索引和备份演练是历史能力，见 [部署归档](archive/pa0-rollout-2026-10.md) 与 [ROG 记录](pa0-rog.md)。

## 可选格式

`formats` 按来源显式启用，默认 `md`。实现支持 `pdf`、`docx/docm`、`xlsx/xlsm`、`pptx/pptm`、`doc/xls/ppt` 的纯文本提取；不做 OCR、图像理解或原始排版预览。带宏的 OOXML 只读取 XML 文本，不执行宏。

Word 保留段落，PDF 保留页码，PowerPoint 保留幻灯片顺序及文本备注，Excel 保留工作表／单元格位置、公式字符串及已有缓存值，不计算公式或获取外部链接。旧 Office 在禁网子进程中临时转换；原文件保持只读。

## 限额与依赖

二进制单文件 128 MiB、ZIP 单成员 64 MiB、解压总量 256 MiB、文本 400 万字符、定位单元 20 万；解析进程 90 秒，旧 Office 转换 45 秒。Linux 额外限制虚拟地址空间与 CPU；LibreOffice 转换在独立网络命名空间执行，禁宏、禁外部更新。macOS 不设置不兼容的 `RLIMIT_AS`，仍执行输入、解压、文本、单元、CPU 和墙钟限额。未变化的失败签名缓存于本机，避免每次核对重复启动转换。

Mac 加密阅读使用既有生产 Python 中的 `cryptography`。扩展 PDF 优先使用 `pdftotext`，否则使用可选 `pypdf`；Linux 旧 Office 转换需要 LibreOffice／UNO 及 `unshare`，合成 PDF 测试另需 `reportlab`。这些格式后端须现场可用并在来源 `formats` 中显式启用，不因代码支持而声称当前 Mac 已索引该格式。Python 可选依赖见 [pyproject.toml](../pyproject.toml)，`asis doctor` 报告实际后端；VPS 中转不需要安装这些解析包。


## PWA 按需阅读

本机来源配置 `remote_evidence: true` 后，还需通过远程元数据路径、排除项与当前 UUID／哈希核验。私密来源／路径／frontmatter 另需 `private_remote_evidence: true` 和私密元数据许可；元数据许可不会自动开放正文。Mac 执行权限变更；本人远程表达授权已获准，管理端点尚未交付。

浏览器每次阅读生成临时 RSA-OAEP 2048／SHA-256 密钥。本机以随机 AES-256-GCM 密钥加密文本及位置，再用浏览器公钥封装密钥；文档 ID、版本、模式、字符游标和客户端随机数绑定到认证数据。浏览器私钥和明文不发送到 VPS。服务端只在内存中保存公钥、任务元数据和密文，最多 32 项、90 秒有效，节点租约 45 秒；无 SQLite／outbox／文件落盘，重启或政策变更会使请求失效。

摘录最多 240 字符；“查看正文”每次最多 6,000 Unicode 字符，前后分段均重新检查文件版本。位置包含在密文中。浏览器通过 `textContent` 展示，关闭、退出或页面隐藏时清除文本，不写 Web Storage、IndexedDB 或服务 Worker 缓存。这里的清除是页面状态清除，不声称能擦除用户截屏或浏览器／系统内存的所有副本。当前飞书搜索插件仍只接收元数据摘要；已批准的本人私聊分析与相关摘录需后续独立实现，不将整个正文默认发到聊天。

PWA 请求需要既有 owner Cookie、Origin／CSRF，并从已有搜索命中选择资料；没有任意路径读取接口。PWA 与协调进程通过权限 `0600` 的本机 Unix socket 连接，节点继续通过出站 SSH 隧道领取工作，没有新增公网本机端口。

Mac 的真实加密链路及用户 PWA 摘录／正文显示已验证；历史 ROG 协议证明保留在部署归档。合成测试覆盖 owner API、CSRF、密文完整性及版本绑定、私密元数据不变成正文许可、撤权、过期、容量限制和 WebCrypto 解密互通。浏览器实际操作和协议验证分别记录在最终验收。


## 可选备份（当前暂缓）

用户已明确暂缓独立备份副本和恢复密钥准备；当前不继续 F 盘传输或密钥导出。已有本机加密状态归档和恢复验证保留，来源云备份由用户自行管理。

实现以本机 AES-256-GCM 加密，密钥留在拥有节点的系统凭据库；VPS 不持有备份或解密密钥。备份只包含来源／连接配置、权限记录、索引及节点任务库，不包含来源原文件、系统凭据或解密密钥。SQLite 通过在线备份 API 创建一致快照，归档清单含 SHA-256。

恢复只写入空的仓库外目录，认证后才解析归档，拒绝路径穿越、链接和未知成员并校验 SQLite。历史演练使用现有系统凭据，不等同于凭据和机器同时丢失的灾难恢复；命令与原演练保留在部署归档，只有用户另行启用时再执行。

当前证明及测试边界见 [最终验收](pa0-acceptance.md)。来源权限、阅读权限和模型权限分开检查，启用新格式不会扩大路径白名单或私密许可。
