# AstrBot 生活增量插件

当前2.5.0：普通本人私聊继续保存为对话记忆，只有`/life`主动记录进入Obsidian随记与习惯／学习投影。作息、明确提醒与已选持续目标各有用途，不因为普通聊天出现“阅读完成”就记为实际读书。PWA反馈对话复用现有原生Agent、选中记录与版本，纠正派生整理并保留回执。见[反馈说明](../../docs/human-feedback.md)。


复用 AstrBot 模型／会话，增加本人生活原话、可修正整理、明确时间事项提醒、生活工作区工具。所有入口检查配置中的唯一 `owner_platform` + `owner_id` 且只接受私聊。没有自动绑定和群聊收录。

主存储实现是 `src/personal_asis/life_store.py`；部署时复制为插件的 `life_store.py`，不依赖 Mac 项目或旧 Relay。`scripts/deploy-life-vps` 只打包必要模块、插件与 Dashboard，验证哈希、备份、切换；失败自动恢复旧代码与服务，不删除生活库。

配置 schema 自带，首次迁移从已有本人绑定生成；后续部署保留配置。普通文本记录不等于模型已成功整理，工具成功前不能回报已整理。提醒 `sending`／`unknown` 不自动重发。

`life_bedtime.py` 共用模块提供本人明确开启的每日01:00／每5分钟催睡，直至晚安，无白天截止。状态和每次投递占位独立保存于原SQLite库的新表，不写入生活事件／同步流；简短晚安自述仍直接记作 `sleep_bed`。`/life sleep`／`on`／`off`、`/life goodnight` 提供确定性控制，不新增LLM工具或shell权限。新库默认关闭，生产启用必须针对既有本人绑定明确执行；日常开关持久保存，不因升级重置。未知发送不重试同一次，后续五分钟催睡继续；停机无积压补发。

`life_context` 按需读取本人授权的带出处初始化背景，`/life forget-context` 删除当前背景和工作区说明。初始化不创建消息或提醒；部署会复制共用的 `bootstrap_context.py` 验证实现。

2.2.0：`/life` 后的非管理命令内容保存后回执“已记下”，随后以 `event.request_llm` 进入当前原生会话／人格／工具流程，保留多行全文，不另造模型循环。普通消息的回复提示自然接住内容，避免播报内部记录字段；晚安回执不再附带整段规则。关闭收录仍可交流，保存失败不能报成功。

`personal_profile.py` 提供草案／已确认的带出处小份本人背景。生产只读取 `personal-profile.json` 中 `approved` 状态；最多4条简要背景进入本人请求，详情由原有 `life_context` 返回，`/life context` 可查看，`forget-context` 同时移除。代码部署不上传本机预览或来源正文，包含Study的真实摘要另需本人确认。

完整范围见[项目规格](../../SPECIFICATION.md)、[运维](../../docs/operations.md)。

2.4.0增加仅本人私聊可用的 `shared_knowledge`：先检索、再逐块读取Life／Study笔记索引文本、五彩与分账号小红书的已采集资料，也可保存本人明确要求的独立补充。共享SQLite与Mac副本经pi_sync固定SSH分页交换，各端只修改自己拥有的记录；不反写Mac原笔记或平台。补充重放幂等，编辑／删除检查版本，来源撤回会停止读取派生补充。原始附件、凭据、会话和绝对路径不传，不自动将整库装进模型上下文。正文共享是2026-10-26本人新选择，与精选背景的独立确认分开。见[共享库](../../docs/shared-library.md)。
# 2.3.0

新增 `life_track`（逐字证据的习惯／开放主题学习整理）、`life_progress`（按日状态与目标）、`life_focus`（最多3个本人选定的持续目标）。当前目标的小份数据随本人原生请求提供，更新可沿用已选定关注范围，不将普通分享自动建成目标。常用明确自述有无模型识别兜底，派生视图失败不谎报原话丢失。

主动简报规则保存在独立SQLite表，每3天08:00–09:00，周一前一周周报合并，最多每天一次；根据已有内容准备回顾、待解问题与下一步提纲，无额外模型循环。数据不足提示补记与 `pi_sync`，不推断未完成。支持“稍后”“这周别问”“恢复跟进”和 `/life proactive on|off`。与催睡及明确事项提醒独立，未知投递不重发。详见[习惯与学习](../../docs/habits-learning.md)。
